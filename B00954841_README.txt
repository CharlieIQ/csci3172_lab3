## Project Description
This project is a REST API for workout exercises using Express and NodeJs. There are three main features:
1. A catalogue of 20 exercises you can browser
2. Workout generation functionality
3. Workout stats tracking

In the custom middleware, `logger.js` prints a timestamp, method, and URL of each request. 
`validate.js` validates the request body against the schema. It reports all errors a given request. 
`errors.js` has an HttpError classn that has a status code, a 404 catch all for nonexistent routes, and a centralized error handler.

## Endpoints
Here is a list of the endpoints I made:
- `GET /`: Lists all endpoints
- `GET /api/exercises: Returns all execsies. Accepts filters where you can search by muscle group and equipment
- `GET /api/exercises/:id`: Returns one exercise
- `GET /api/muscle-groups`: Lists each muscle group and a count of exercises in it
- `GET /api/workout/random?muscle=&count=`:  Returns a random workout, default of 4 and a max of 10
- `GET /api/log?exerciseId=`: Read the exercise log
- `POST /api/log`: Add a log entry for an exercise
- `GET /api/stats`: Returns total sets logged, total volume, sets per muscle group, and most trained muscle group
- `POST /api/exercises`: Adds an exercise
